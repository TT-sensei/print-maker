# プリント工房

パーツを組み合わせて、授業・宿題・ミニテスト・振り返り用のプリントを短時間で作る先生向けWebアプリです。

## 主な機能

- A4縦／横、横書き／縦書き、余白設定
- 問題、説明、記述欄、計算欄、5mm方眼、漢字練習マス、表、画像、NAVIイラストなど16種のパーツ
- 100%／66%／50%／33%幅による崩れにくい横並び
- A4を超えたときのパーツ単位の自動改ページ
- 用紙上の文章と表セルを直接編集
- 児童用／先生用の切り替えと解答表示
- Undo／Redo（最大30操作）
- localStorageによる自動保存、プリント保存、マイテンプレート、コピーして新規作成
- JSON入出力によるバックアップとAIとのデータ受け渡し
- アップロード画像の自動軽量化
- ブラウザ標準印刷／PDF保存
- PC、Chromebook、iPad向けレスポンシブUI

外部API、サーバー、DB、外部フォントは使用していません。画像アップロードを除く作成データは、利用中のブラウザ内に保存されます。

## 公開

GitHub Pagesで `main` ブランチのルートを公開すると、そのまま利用できます。
