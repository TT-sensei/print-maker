# プリント工房

授業・宿題・ミニテスト・振り返りなどのプリントを、パーツを組み合わせて作成できる先生向けWebアプリです。

**公開ページ：** https://tt-sensei.github.io/print-maker/

## できること

- A4縦・横、横書き・縦書き、余白の設定
- 問題文、説明文、記述欄、計算欄、表、画像などのパーツを配置
- チェックリスト、比較欄、線で結ぶ、思考の流れ、語群・ヒント、吹き出し、自己評価、順序カードなどを追加
- パーツの幅を100%・66%・50%・33%から選び、横に並べてレイアウト
- 用紙を超える場合は、パーツ単位で自動的に改ページ
- 児童用・先生用の切り替え、解答の表示
- Undo／Redo（最大30操作）
- ブラウザで印刷、またはPDFとして保存

## 用紙を見ながら直接編集

設定パネルを開かなくても、用紙上の文字をタップ・クリックして直接編集できます。

- 題名、サブタイトル
- 問題文、説明、めあて、問い、まとめ、振り返り
- 選択肢、チェック項目、手順、語群、吹き出し
- 表の文字、比較欄、順序カード、線で結ぶ項目、評価表の項目など

用紙上で編集した内容は、設定パネル側にも反映されます。編集した文字は自動保存されます。

## テンプレート

教科や授業の目的に合わせて、次のようなテンプレートから作成を始められます。

- 算数、国語、縦書き、漢字、理科、社会
- ミニテスト、振り返り、自分で学ぶ、考えを比べる
- 読解、意見文、話し合い、実験・観察、資料分析、順序整理
- 線で結ぶ、単元まとめ、相互評価、発表
- やさしい学習、家庭学習、授業の終わりカード

テンプレートを選んだ後も、パーツや文章を自由に調整できます。

## 保存・データの管理

- 作成中のデータはブラウザ内に自動保存
- プリントの保存、マイテンプレートへの登録、コピーして新規作成
- JSON形式での書き出し・読み込みによるバックアップ
- JSONデータを使った、AIなど外部ツールとのデータ受け渡し
- アップロード画像の自動軽量化

ブラウザのデータ削除や端末変更に備え、必要に応じてJSON形式でバックアップしてください。

## 動作と技術方針

- HTML・CSS・JavaScriptによる静的Webアプリ
- 外部API、サーバー、データベース、外部フォントは使用していません
- 作成データは利用中のブラウザ内に保存されます
- PC、Chromebook、iPadなどの画面幅に対応
- GitHub Pagesで公開
